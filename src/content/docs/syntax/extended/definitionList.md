A **definition list** is an element which allows for the creation of lists of terms followed by their definitions.

## Example Syntax

```text
First Term
: This is the definition of the first term.
```

```html
<dl>
    <dt>First Term</dt>
    <dd>This is the definition of the first term.</dd>
</dl>
```
